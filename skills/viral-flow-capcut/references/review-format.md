# Two-flow review format

Use Traditional Chinese/Cantonese by default. Titles and section labels are for the written review only; do not add them to the video.

## Submission structure

1. One line explaining the two narrative approaches and that this is the review stage.
2. Version A: title, estimated runtime, and complete spoken text in sequence.
3. Version B: same level of detail, not an abbreviated alternative.
4. One short comparison and a clear request to approve or revise.

When the host supports finished writing blocks, use one document block per flow. Otherwise use ordinary Markdown. Preserve existing block IDs when revising in the same conversation.

### Sections to adapt, not blindly fill

- Complete hook.
- “Soft voice, wild truth” + the source video's next English sentence.
- Background that makes the speaker's reaction understandable.
- Concrete experience, obstacle or conversation.
- Reversal / what did not go as expected.
- New understanding grounded in that experience.
- What the creator now does or sees differently.
- Ending that answers or reinterprets the hook.

Keep exact original phrasing where possible. If readable text is normalized, say so once and keep source timestamps for each selection. Do not smooth a script so extensively that it becomes uncuttable without new speech. Explicitly mark uncertain words and new-recording requirements.

## Review checks before showing the user

- Read each flow start to finish as if unfamiliar with the person.
- Every “he/she/it/that”, “later”, “but” and “so” has a recoverable referent.
- Concrete achievements have enough context to explain their significance.
- Reflection follows evidence; the ending is earned by preceding content.
- The two versions differ meaningfully, even when they share most source material.
- Runtime is the sum of proposed source spans; it is not a target invented from the benchmark.
- The user can approve the complete words/order they will actually receive.

## Revision behaviour

“Too short / no beginning or ending”: restore necessary background, transitions, examples and present-day implications; don't just insert filler or slow the footage.

“Hook is incomplete”: add the missing relationship between situation, contradiction and emotional consequence using recorded sentences. Re-check the body for duplicate content.

“Let me see both again”: return both complete current flows. Do not start cutting.

“Yes, follow these two flows and cut”: record approval, execute both and deliver exports; do not re-ask at each technical step.
