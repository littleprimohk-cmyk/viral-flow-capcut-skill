# 給團隊的安裝與示範講解

可用於現場或視像會議，約 5–8 分鐘。以下講解不要求同事懂程式。

## 1. 先解釋這套 skill 做甚麼

「我們不是每次重新教 AI 怎樣剪片。這套 skill 保留了爆紅參考的故事結構，也保留我們的工作規矩：先看兩個完整文字 flow，批了才剪。最終會有兩條影片。」

重點展示：Hook → 固定品牌句＋英文 → 完整故事 → 反轉 → 現在的改變 → 回扣結尾。

## 2. 安裝示範

打開 GitHub 的 `skills/viral-flow-capcut` 資料夾，複製網址；在 Codex 用 `$skill-installer` 要求安裝。如果沒有 GitHub 權限，可由已獲授權的人提供套件 ZIP，再依 README 的本機方法安裝。

「安裝的是工作流程，不是 CapCut。你仍需要本機 CapCut、Whisper／FFmpeg 和可以操作 App 的 Codex 工具。」

## 3. 驗證已安裝

在新回合輸入：

> 用 $viral-flow-capcut，先說明你收到新影片後會怎樣處理。不要操作 CapCut。

正確回應應提及：

- 本機 Whisper 轉錄和原片核對。
- A、B 兩個完整文字 flow。
- Hook 後保留品牌句及該片英文。
- 等使用者批准才剪。
- 預設不加字，最終交兩條成片。

若沒有辨認到 skill，請 Codex 檢查 `SKILL.md` 是否直接放在 `viral-flow-capcut` 資料夾內、安裝位置是否可被當前環境讀取；必要時重新啟動 Codex。

## 4. 示範提供影片和改 Hook

提供一條自己有權使用的口播影片，再貼 README 的「第一次使用」提示。展示兩個全文，然後要求改一個 Hook。

「我們要看的不是只有標題。每個版本都要有完整講法，知道從哪個故事開始、怎樣轉折、最後想讓人記住甚麼。覺得太短、沒頭沒尾，就要求補回必要細節。」

提醒：認同 Hook 不等於批准剪整條片。

## 5. 批准後看成品

貼：「A、B 兩個全文都批准，現在用 CapCut 剪出兩條無新增文字的原聲影片。」

完成後檢查：

1. 兩個版本的 Hook 是否不同且完整。
2. 品牌句＋英文是否緊接 Hook。
3. 接駁有沒有斬字、突然改意思或不必要重複。
4. 結尾有沒有完整收束。
5. 兩條影片能否播放、有原聲，並且 CapCut 專案可再編輯。

## 常見問題

**只安裝 skill，為甚麼不能自動操作 CapCut？**
Skill 是指令包。需要宿主另外提供本機 App 操作能力；沒有該工具時，先完成文字 flow 和時間碼，待工具可用才剪。

**一定要剪成 55 秒嗎？**
不用。55 秒是參考片長度；本次完整案例最後約 97 秒及 94 秒。保留故事因果比照抄片長重要。

**是不是用同一句英文開場？**
固定的是 “Soft voice, wild truth”。後面那句英文取自這次原片；缺少就先提出，不生成假原聲。

**能否加字幕？**
預設不加。若這次要字幕或其他設計，請明確說明，那是新增的製作範圍。
